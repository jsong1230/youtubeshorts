Privacy Policy

Last updated: 21 November 2025

This Privacy Policy describes how the Shorts Automation bot (“Service”) collects, uses, and stores information. The Service is an open-source automation tool located at github.com/jsong1230/youtubeshorts.

1. Information We Collect

  • API Credentials: Access tokens, refresh tokens, client IDs, and secrets for services such as YouTube, TikTok, Instagram, OpenAI, Anthropic, etc. These values remain on your machine (e.g. `.env`, `token.json`) and are not transmitted to any external server we control.
  • Generated Media: Videos, audio files, subtitles, and thumbnails created locally in the `output/` directory.
  • Operational Logs: Console logs describing progress, errors, or API responses. These stay in your environment unless you explicitly share them.

2. How Information Is Used

Data is used solely to:

  • Generate videos and related creative assets
  • Authenticate with third-party APIs on your behalf
  • Upload videos to platforms you have explicitly enabled
  • Persist run history inside the local SQLite database

3. Data Control & Storage

All sensitive information stays on the user’s device or infrastructure. The maintainers of the repository do not collect or store your API keys, generated media, or telemetry. Removing the `.env`, `token.json`, and `data/videos.db` files deletes the associated sensitive data.

4. Third-Party Services

The Service communicates directly with external APIs (YouTube Data API, TikTok Open API, Instagram Graph API, OpenAI, Anthropic, etc.). Each provider’s privacy policies apply when their services are used. We do not control how those providers handle your information.

5. Security

Because this is a self-hosted project, you are responsible for safeguarding your environment. Keep API keys private, avoid committing `.env` files to public repositories, and rotate tokens if you suspect unauthorized access.

6. Children’s Privacy

The Service is intended for users who are eligible to operate the external APIs involved. It should not be used by children under the age required by each platform’s policies.

7. Changes to This Policy

We may update this Privacy Policy periodically. Updates will be posted at this URL with a revised “Last updated” date. Continued use of the Service after changes indicates acceptance.

8. Contact

Questions? Please open an issue in the GitHub repository linked above.
