# 저작권 안전성 가이드

이 프로젝트는 **100% 저작권 안전한 콘텐츠**를 생성하기 위해 설계되었습니다.

## ✅ 사용하는 저작권 안전한 소스

### 1. 스크립트 (텍스트)
- **AI 생성**: OpenAI GPT 모델로 생성된 원본 텍스트
- **저작권**: 100% 본인 소유 (AI 생성 콘텐츠는 사용자 소유)

### 2. 음성 (TTS)
- **gTTS (Google Text-to-Speech)**: Google의 무료 TTS 서비스
- **OpenAI TTS**: OpenAI의 TTS API
- **저작권**: 생성된 음성은 본인 소유

### 3. 배경 이미지
다음 무료 라이선스 소스를 사용합니다:

#### Pexels (CC0 라이선스)
- **라이선스**: CC0 (Public Domain)
- **상업적 사용**: ✅ 가능
- **저작권 표시**: 불필요
- **API**: https://www.pexels.com/api/

#### Unsplash (Unsplash License)
- **라이선스**: Unsplash License
- **상업적 사용**: ✅ 가능
- **저작권 표시**: 권장 (선택사항)
- **API**: https://unsplash.com/developers

#### Pixabay (Pixabay License)
- **라이선스**: Pixabay License (CC0 유사)
- **상업적 사용**: ✅ 가능
- **저작권 표시**: 불필요
- **API**: https://pixabay.com/api/docs/

### 4. 배경 영상
#### Pexels Video (CC0 라이선스)
- **라이선스**: CC0 (Public Domain)
- **상업적 사용**: ✅ 가능
- **저작권 표시**: 불필요
- **API**: Pexels Video API 사용

## ❌ 사용하지 않는 것

### 저작권이 있는 콘텐츠
- **게임 영상**: Subway Surfers, Minecraft 등 (저작권 있음)
- **브레인롯 영상**: 게임 플레이 영상은 사용하지 않음
- **저작권이 있는 음악**: 사용하지 않음
- **저작권이 있는 이미지**: 사용하지 않음

## 🎯 브레인롯 스타일 영상 생성

브레인롯 스타일 영상을 원하는 경우:
1. **AI 생성 배경**: 그라데이션 및 시각적 효과 사용
2. **무료 영상 소스**: Pexels Video에서 다운로드한 CC0 영상 사용
3. **직접 제작**: AI로 생성한 시각적 요소 조합

**절대 사용하지 않음**: Subway Surfers, Minecraft 등 게임 플레이 영상

## 📝 라이선스 확인

모든 외부 소스는 다음 조건을 만족합니다:
- ✅ CC0 (Public Domain)
- ✅ Unsplash License
- ✅ Pixabay License
- ✅ 상업적 사용 가능
- ✅ 저작권 표시 불필요 (또는 선택사항)

## 🔒 안전성 보장

1. **자동 검증**: 코드는 CC0/무료 라이선스 소스만 사용
2. **API 필터링**: Pexels, Unsplash, Pixabay API는 자동으로 무료 라이선스 콘텐츠만 반환
3. **수동 확인**: 필요시 각 소스의 라이선스를 확인할 수 있음
