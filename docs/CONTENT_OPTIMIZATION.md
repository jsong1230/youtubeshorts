# 콘텐츠 최적화 가이드

이 프로젝트는 **수익화 최적화된 콘텐츠 형태**를 지원합니다.

## 🎯 지원하는 콘텐츠 타입

### 1. Hook (한국어 한 문장 학습)

- **특징**: 짧고 강한 Hook으로 시작
- **길이**: 55초 (목표)
- **구조**: Hook 문장 → 설명 → 반복/강조
- **대표 기본 주제**:
  - 💸 돈/재테크: “월급만으로는 절대 부자가 안 되는 이유”, “카드값이 항상 빠듯한 사람들의 한 가지 습관”, “평범한 직장인이 재테크로 앞서는 가장 현실적인 방법”
  - 🧠 자기계발: “하루 루틴 10분이 인생의 방향을 바꾸는 이유”, “성공하는 사람들은 ‘동기부여’ 대신 이것을 씁니다”
  - 🏠 생활 정리: “집이 항상 정리된 사람들의 아주 단순한 기준 하나”, “냉장고가 엉망인 집은 돈 관리도 엉망인 경우가 많습니다”
  - 🚨 리스크/위기관리: “한 번의 사고가 수년치 저축을 날려버리는 순간”, “보험이 있어도 파산하는 사람들의 공통점”
- **계절 우선 주제**:
  - 봄: 새 계절 정리, 새해 계획 리마인드
  - 여름: 휴가·전기요금·지출 관리
  - 가을: 하반기 점검, 목표 재정비
  - 겨울: 난방비·연말 소비·연말 정산

### 2. Quote (AI·비즈니스·명언·지식 한 줄)

- **특징**: 강력한 명언이나 인사이트로 시작
- **길이**: 55초 (목표)
- **구조**: 명언 → 설명 → 실생활 적용법
- **대표 기본 주제**:
  - 돈/재테크: “돈은 금액이 아니라 방향이 중요하다.”, “부의 차이는 한 번의 선택이 아니라 반복된 선택에서 나온다.”
  - 자기계발: “동기부여는 시작을 돕지만, 루틴은 끝까지 가게 만든다.”, “오늘 1% 나아지면, 1년 뒤에는 다른 사람이 된다.”
  - 생활/정리: “공간을 정리하면 생각이 정리되고, 생각이 정리되면 불안이 줄어든다.”
- **계절 우선 주제**:
  - 봄: 성장·정리 명언
  - 여름: 지출·우선순위 메시지
  - 가을: 반복된 선택, 루틴 점검
  - 겨울: 돈의 방향, 루틴의 힘

### 3. Story (스토리텔링)

- **특징**: 심리/역사/부자습관 등 스토리로 교훈 전달
- **길이**: 55초 (목표)
- **구조**: Hook → 전개 → 교훈 → 마무리
- **대표 기본 주제**:
  - 돈/재테크: “월급 280으로 살던 사람이 3년 만에 자산 3억 만든 이야기”, “카드값에 쫓기던 직장인이 자동이체 한 번 바꾸고 버텨낸 1년”
  - 자기계발/일: “계획만 세우던 사람이 ‘실행하는 사람’으로 바뀐 계기”, “매일 야근하던 사람이 퇴근 시간을 지키기 시작한 이유”
  - 생활/집: “집 한 구석을 정리했을 뿐인데 인간관계가 바뀐 이야기”, “옷장 정리 후 아침마다 결정 피로가 사라진 사례”
- **계절 우선 주제**:
  - 봄: 실행력·정리 스토리
  - 여름: 지출 관리 사례
  - 가을: 자산 성장·옷장 정리
  - 겨울: 대출/루틴으로 버틴 이야기

### 4. Fact (숏폼 팩트 기반)

- **특징**: 놀라운 팩트로 Hook 생성
- **길이**: 55초 (목표)
- **구조**: 팩트 → 설명 → 왜 놀라운지 강조
- **대표 기본 주제**:
  - 돈/재테크: “연봉이 늘어도 저축률이 그대로면 자산은 거의 늘지 않는다.”, “복리는 금액이 아니라 ‘시간을 얼마나 오래 버티느냐’의 싸움이다.”
  - 생활/정리: “집이 어지러운 사람은 중요한 결정을 미루는 경향이 크다.”, “옷이 많을수록 실제로 입는 옷은 20% 안팎”
  - 위기관리: “예상치 못한 지출 대부분은 준비하지 않은 영역에서 터진다.”
- **계절 우선 주제**:
  - 봄: 카테고리 단순화, 옷장 사실
  - 여름: 냉장고·전기요금 이슈
  - 가을: 수입 대비 저축률 점검
  - 겨울: 예상치 못한 지출·사고 대비

### 5. Short Story (AI 이미지 기반 짧은 스토리)

- **특징**: 인생 교훈, 영감, 성공 스토리
- **길이**: 55초 (목표)
- **구조**: Hook → 사건 → 교훈 → 마무리
- **대표 기본 주제**:
  - 생활/정리: “옷장을 비우고 나서야, 내가 진짜 좋아하는 스타일이 보였다.”, “책상 서랍 하나를 정리했을 뿐인데, 미뤄둔 일을 시작하게 되었다.”
  - 돈/습관: “한 달 지출을 적어봤더니 스트레스 패턴이 드러났다.”, “계좌를 여러 개로 나눴더니 쓸 돈과 모을 돈이 구분되기 시작했다.”
  - 자기계발: “퇴근 후 10분 루틴을 만들었더니 다음 날 아침이 달라졌다.”
- **계절 우선 주제**:
  - 봄: 정리·새 시작 스토리
  - 여름: 지출 기록에서 드러난 행동 패턴
  - 가을: 계좌 분리, 자산 정리
  - 겨울: 루틴·기록으로 버틴 경험

## ⚙️ 설정 방법

### 환경 변수 (.env)

```bash
# 콘텐츠 타입 설정
CONTENT_TYPE=auto  # 'hook', 'quote', 'story', 'fact', 'short_story', 'auto'

# 영상 길이: 모든 타입 55초 목표 (최대 60초)
# PREFER_SHORT_VIDEOS 설정은 더 이상 사용되지 않음
```

### 계절별 주제 선택

시스템은 자동으로 현재 날짜를 기반으로 계절을 판단하고, 계절에 맞는 주제를 우선적으로 선택합니다 (25% 확률):

- **봄 (3-5월)**: 정리, 옷장 정리, 환절기 대비
- **여름 (6-8월)**: 전기요금 절약, 장마철 곰팡이, 습기 관리
- **가을 (9-11월)**: 환절기 정리, 겨울 준비, 옷장 정리
- **겨울 (12-2월)**: 난방비 절약, 자동차 점검, 겨울 대비

### AI 스크립트 생성 & 언어 정책

- **언어 통일**: 모든 스크립트·자막·썸네일 텍스트는 영어로만 생성됩니다. 한국어 주제를 입력해도 내부에서 영어 번역 프롬프트로 변환되어 일관성을 유지합니다.
- **프로바이더 우선순위**: `AI_API_PROVIDER`에 따라 Claude → OpenAI 순으로 시도합니다. Claude 사용 시 `claude-3-opus-20240229`, `claude-3-sonnet-20240229`, `claude-3-5-sonnet-20241022` 순으로 호출해 404 모델을 마지막으로 미룹니다.
- **안전 필터링**: AI가 반환한 문장 중 “Here’s a YouTube Shorts script…” 처럼 안내성 문구나 `script`, `shorts`가 포함된 제작 지시 문장은 자동 제거하여 음성에 실리지 않도록 했습니다.
- **기본 스크립트**: 모든 모델 호출이 실패하면 주제 키워드가 반영된 12~16문장짜리 기본 스크립트를 사용해도 55초 분량이 확보되도록 했습니다.

```bash

PREFER_SHORT_VIDEOS=true
```

#### 스토리텔링 영상

```bash
CONTENT_TYPE=story
PREFER_SHORT_VIDEOS=true
```

#### 팩트 기반 영상

```bash
CONTENT_TYPE=fact
```

#### 짧은 스토리 영상


## 📊 수익화 최적화 이유

이런 콘텐츠 형태가 수익화에 유리한 이유:

1. **저작권 위험 없음**
   - 모든 콘텐츠가 AI 생성 또는 CC0 라이선스
   - 게임 영상, 저작권 있는 콘텐츠 사용 안 함

2. **적절한 길이로 완료율 높음**
   - 55초 영상은 시청 완료율이 높음
   - YouTube Shorts 최적 길이 (최대 60초)
   - 충분한 내용으로 시청자 만족도 향상

3. **조회수 폭발 확률 높음**
   - 강력한 Hook으로 첫 3초 안에 관심 유도
   - 계절/생활/재테크 등 실용적인 주제로 공유 유도
   - 알고리즘 추천에 유리한 구조

4. **계절 맞춤 콘텐츠**
   - 현재 계절에 맞는 주제 자동 선택
   - 시의성 있는 콘텐츠로 시청자 관심도 향상
   - 실용적인 정보로 재방문 유도

5. **퀄리티 중심 전략**

   - 하루 1개의 고품질 영상에 집중
   - 6가지 콘텐츠 타입 중 최적의 타입을 선택하여 고품질 영상 생성
   - 양보다 질에 집중하여 시청자 참여도와 수익을 극대화

### 스토리텔링 영상 생성

```bash
CONTENT_TYPE=story python main.py upload
```

### 팩트 기반 영상 생성

## 💡 최적화 팁

1. **Hook 강화**: 첫 3초가 가장 중요합니다

2. **충분한 내용**: 55초 분량으로 자세한 설명과 예시 포함
3. **다양성**: 스케줄러가 자동으로 6개 타입 모두 생성하여 다양성 확보
4. **계절 맞춤**: 계절에 맞는 주제가 자동으로 우선 선택되어 시청자 관심도 향상
5. **성과 분석**: 데이터베이스에서 성과 좋은 타입 확인
6. **자동 선택**: `CONTENT_TYPE=auto`로 다양성 확보

## 📈 성과 추적

데이터베이스에서 다음 정보를 확인할 수 있습니다:

- 콘텐츠 타입별 평균 조회수
- 콘텐츠 타입별 참여율
- 성과 좋은 콘텐츠 타입

성과 기반 프롬프트가 자동으로 적용되어 점점 더 좋은 콘텐츠를 생성합니다.
