# 콘텐츠 최적화 가이드

이 프로젝트는 **수익화 최적화된 콘텐츠 형태**를 지원합니다.

## 🎯 지원하는 콘텐츠 타입

### 1. Hook (한국어 한 문장 학습)
- **특징**: 짧고 강한 Hook으로 시작
- **길이**: 55초 (목표)
- **구조**: Hook 문장 → 설명 → 반복/강조
- **주제 카테고리**:
  - 🔥 계절: 여름 전기요금, 장마철 곰팡이, 가을 환절기 정리, 겨울 준비
  - 🏠 생활: 집 정리, 냉장고 관리, 옷장 정리, 자동차 점검
  - 💰 재테크: 월급 관리, 부자 습관, 투자 마인드
  - 🧠 자기계발: 아침 루틴, 성공 습관, 사고방식

### 2. Quote (AI·비즈니스·명언·지식 한 줄)
- **특징**: 강력한 명언이나 인사이트로 시작
- **길이**: 55초 (목표)
- **구조**: 명언 → 설명 → 실생활 적용법
- **주제 카테고리**:
  - 🌤 계절·생활: 정리 명언, 계절 변화, 깨끗한 집, 루틴의 힘
  - 💸 돈·재테크: 돈 관리, 투자 원칙, 부의 차이, 경제적 자유
  - 🧠 자기계발: 루틴과 습관, 꾸준함의 힘, 1% 성장

### 3. Story (스토리텔링)
- **특징**: 심리/역사/부자습관 등 스토리로 교훈 전달
- **길이**: 55초 (목표)
- **구조**: Hook → 전개 → 교훈 → 마무리
- **주제 카테고리**:
  - 🌤 계절·라이프: 장마철 곰팡이 해결, 겨울 난방비 절약, 옷장 정리 변화, 자동차 점검 실화
  - 💸 돈·재테크: 월급 280에서 자산 3억, 자동투자로 인생 변화, 소비 습관 개선, 경제적 자유 달성
  - 🧠 자기계발: 하루 10분 루틴 변화, 계획에서 실행으로

### 4. Fact (숏폼 팩트 기반)
- **특징**: 놀라운 팩트로 Hook 생성
- **길이**: 55초 (목표)
- **구조**: 팩트 → 설명 → 왜 놀라운지 강조
- **주제 카테고리**:
  - 🌤 계절·생활: 여름 전기요금 새는 지점, 가을 환절기 집 더러워지는 이유, 겨울 난방비 차이, 옷 변색 이유
  - 🚗 자동차: 겨울철 엔진오일 점검, 타이어 마모 위험, 와이퍼 계절별 교체
  - 💰 돈·경제: 부자들의 지출 기록, 복리의 수학적 비밀, ETF 초보 장점
  - 🧠 자기계발: 아침 루틴과 집중력, 작은 습관의 힘

### 5. Short Story (AI 이미지 기반 짧은 스토리)
- **특징**: 인생 교훈, 영감, 성공 스토리
- **길이**: 55초 (목표)
- **구조**: Hook → 사건 → 교훈 → 마무리
- **주제 카테고리**:
  - 🌤 계절·정리·생활: 옷장 정리로 스트레스 감소, 겨울 대비로 난방비 절반, 냉장고 구역별 관리, 습기 관리로 냄새 제거
  - 💸 돈: 적금에서 자동투자로 변화, 지출 점검으로 통장 변화
  - 🧠 자기계발: 하루 5분 루틴 변화, 작은 선택의 큰 영향

## ⚙️ 설정 방법

### 환경 변수 (.env)

```bash
# 콘텐츠 타입 설정
CONTENT_TYPE=auto  # 'hook', 'quote', 'story', 'fact', 'short_story', 'auto'

# 영상 길이: 모든 타입 55초 목표 (최대 60초)
# PREFER_SHORT_VIDEOS 설정은 더 이상 사용되지 않음
```

### 계절별 주제 선택

시스템은 자동으로 현재 날짜를 기반으로 계절을 판단하고, 계절에 맞는 주제를 우선적으로 선택합니다 (50% 확률):

- **봄 (3-5월)**: 정리, 옷장 정리, 환절기 대비
- **여름 (6-8월)**: 전기요금 절약, 장마철 곰팡이, 습기 관리
- **가을 (9-11월)**: 환절기 정리, 겨울 준비, 옷장 정리
- **겨울 (12-2월)**: 난방비 절약, 자동차 점검, 겨울 대비

### 콘텐츠 타입별 설정

#### Hook 영상
```bash
CONTENT_TYPE=hook
PREFER_SHORT_VIDEOS=true
```

#### 명언/지식 영상
```bash
CONTENT_TYPE=quote
PREFER_SHORT_VIDEOS=true
```

#### 스토리텔링 영상
```bash
CONTENT_TYPE=story
PREFER_SHORT_VIDEOS=true
```

#### 팩트 기반 영상
```bash
CONTENT_TYPE=fact
PREFER_SHORT_VIDEOS=true
```

#### 짧은 스토리 영상
```bash
CONTENT_TYPE=short_story
PREFER_SHORT_VIDEOS=true
```

#### 자동 선택 (랜덤)
```bash
CONTENT_TYPE=auto
PREFER_SHORT_VIDEOS=true
```

## 📊 수익화 최적화 이유

이런 콘텐츠 형태가 수익화에 유리한 이유:

1. **저작권 위험 없음**
   - 모든 콘텐츠가 AI 생성 또는 CC0 라이선스
   - 게임 영상, 저작권 있는 콘텐츠 사용 안 함

2. **적절한 길이로 완료율 높음**
   - 55초 영상은 시청 완료율이 높음
   - YouTube Shorts 최적 길이 (최대 60초)
   - 충분한 내용으로 시청자 만족도 향상

3. **조회수 폭발 확률 높음**
   - 강력한 Hook으로 첫 3초 안에 관심 유도
   - 계절/생활/재테크 등 실용적인 주제로 공유 유도
   - 알고리즘 추천에 유리한 구조

4. **계절 맞춤 콘텐츠**
   - 현재 계절에 맞는 주제 자동 선택
   - 시의성 있는 콘텐츠로 시청자 관심도 향상
   - 실용적인 정보로 재방문 유도

5. **다양성 확보**
   - 스케줄러가 6개 타입 모두 자동 생성
   - 같은 주제를 다른 각도로 재생성 가능
   - 다양한 콘텐츠 타입으로 채널 다양성 확보

### 명언 영상 생성

```bash
CONTENT_TYPE=quote python main.py upload
```

### 스토리텔링 영상 생성
```bash
CONTENT_TYPE=story python main.py upload
```

### 팩트 기반 영상 생성
```bash

```

```bash

```

## 💡 최적화 팁

1. **Hook 강화**: 첫 3초가 가장 중요합니다
2. **충분한 내용**: 55초 분량으로 자세한 설명과 예시 포함
3. **다양성**: 스케줄러가 자동으로 6개 타입 모두 생성하여 다양성 확보
4. **계절 맞춤**: 계절에 맞는 주제가 자동으로 우선 선택되어 시청자 관심도 향상
5. **성과 분석**: 데이터베이스에서 성과 좋은 타입 확인
6. **자동 선택**: `CONTENT_TYPE=auto`로 다양성 확보

## 📈 성과 추적

데이터베이스에서 다음 정보를 확인할 수 있습니다:
- 콘텐츠 타입별 평균 조회수
- 콘텐츠 타입별 참여율
- 성과 좋은 콘텐츠 타입

성과 기반 프롬프트가 자동으로 적용되어 점점 더 좋은 콘텐츠를 생성합니다.
